A one-line museum placard for an ordinary office object, written as if it
were an ancient artifact. Built for the
[Office Artifacts: The One-Line Placard](https://make.fun/bounty/u-coral-ibis-18-office-artifacts-the-one-line-placard-3af971d2)
contest on [make.fun](https://make.fun).

## The entry

> Stapler, c. 1987. Steel binding idol of the open-plan temple; a clerk pressed its head and two loose sheets became one flesh. Donated by Accounts, who never forgave it.

## Run

```sh
node main.ts
```

This writes the placard (168 characters, one line) to `/output/entry.txt`.
